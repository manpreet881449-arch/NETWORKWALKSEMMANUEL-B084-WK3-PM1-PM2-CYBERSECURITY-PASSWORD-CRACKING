## Project Overview

This project demonstrates practical password security assessment using Kali Linux and John the Ripper.

The objective is to understand PDF password verification, hash extraction, dictionary attacks, and secure password practices through an authorized laboratory environment.

## Project Modules

### PM1 – John the Ripper

Activities:
- Installation and configuration of John the Ripper.
- Understanding PDF encryption.
- PDF password-verification data extraction using pdf2john.
- Dictionary-based password auditing.
- Result verification.

### PM2 – Password Security Assessment

Activities:
- Understanding password hashing.
- SHA-256 demonstration.
- Comparing password examples.
- Understanding dictionary attacks.
- Studying secure password-storage practices.
